# ICP 备案号展示要求（官方依据）

核对日期：2026-09-01。本文仅整理中国大陆非经营性互联网信息服务的备案号展示规则，不构成法律意见。

## 结论

| 问题 | 结论 | 官方依据 |
| --- | --- | --- |
| 备案号是否必须展示？ | **是。** 互联网信息服务提供者须在网站主页的显著位置标明经营许可证编号或备案编号；非经营性服务还须遵守更具体的备案规则。 | [《互联网信息服务管理办法》第十二条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_4c6a91eb93c34a6e8adc5852f9b56fd1.html) |
| 是否必须在中间？ | **是，针对非经营性网站，规章明确为“主页底部的中央位置”。** 因此备案号不宜仅放在页脚左栏或任意一栏；应在整页页脚的可见居中区域展示。 | [《非经营性互联网信息服务备案管理办法》第十三条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html) |
| 是否需要链接？ | **需要。** 备案号下方应按要求链接工业和信息化部备案管理系统，供公众查询核对。工信部省级通信管理局的办事指南明确该地址为 `https://beian.miit.gov.cn`。 | [办法第十三条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)；[工信部甘肃省通信管理局办事指南](https://gsca.miit.gov.cn/bsfw/bszn/art/2020/art_82d75f07581447f5a8cf74db402554f2.html) |
| 仅让程序或爬虫抓到、不给普通访问者显示，可以吗？ | **不应视为合规。** 规章要求在主页具体位置“标明”，并明确目的为“供公众查询核对”；仅存在于 HTML、meta、结构化数据、隐藏元素或爬虫专用内容，并未向正常访问主页的公众展示，不能满足该要求。官方规则未规定 CSS 像素、字体大小或专门讨论“爬虫可见”的技术情形；上述结论是对明文义务作出的保守合规判断。 | [《互联网信息服务管理办法》第十二条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_4c6a91eb93c34a6e8adc5852f9b56fd1.html)；[《非经营性互联网信息服务备案管理办法》第十三条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html) |

## 建议的保守实现

在首页页脚的整体底部居中位置，以正常文本清晰展示备案号，例如 `蜀ICP备2026050765号`；不要使用 `display: none`、`visibility: hidden`、零尺寸、移出可视区域或只针对爬虫输出的做法。备案号下方放置一个面向访客可点击、直达 `https://beian.miit.gov.cn/` 的链接。这样最贴近“主页底部的中央位置”和“备案编号下方链接”的文字要求。

现行规则没有给出精确的 CSS 布局标准。因此“居中”宜按正常桌面和移动端访问时，备案号相对于整个页脚/页面底部可见居中来实现，而非只在某个多栏页脚的中间或左侧内容栏中出现。

## 执法后果与边界

- 未在主页标明备案号：主管部门可责令改正，并处 5,000 元以上 50,000 元以下罚款。[《互联网信息服务管理办法》第二十二条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_4c6a91eb93c34a6e8adc5852f9b56fd1.html)
- 未在备案号下方链接工信部备案管理系统：省通信管理局可责令限期改正；逾期不改正的，处 5,000 元以上 10,000 元以下罚款。[《非经营性互联网信息服务备案管理办法》第二十五条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)
- 当前版本依据为工信部于 2024 年公布的修订文本。该次修订取消了网站目录中放置“备案电子验证标识”的要求，但**没有**取消备案号的可见展示、底部中央位置或备案系统链接要求。[工信部对第 68 号令的官方解读](https://www.miit.gov.cn/jgsj/zfs/gzdt/art/2024/art_a601a4e8a9d54cdb9369a24812d5ec91.html)
